# Política de seguridad

Gracias por ayudar a mantener este proyecto seguro.

## Reporte de vulnerabilidades

Si encuentras una vulnerabilidad:

1. **No publiques detalles sensibles** en issues públicos.
2. Abre un issue describiendo el problema de forma general e indica que se trata de un reporte de seguridad.
3. Un mantenedor responderá con los siguientes pasos.

## Alcance

Esta política aplica a todo el contenido en el repositorio.
