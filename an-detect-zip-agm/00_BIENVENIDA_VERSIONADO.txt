⚡ COMANDOS RÁPIDOS
────────────────────────────────────────────────────────────────────────────

VER VERSIÓN ACTUAL:
    python version.py
    python version_manager.py --show

BUMPING DE VERSIONES:
    python version_manager.py --patch    # 1.0.0 → 1.0.1 (bug fix)
    python version_manager.py --minor    # 1.0.0 → 1.1.0 (new feature)
    python version_manager.py --major    # 1.0.0 → 2.0.0 (breaking)

CAMBIAR ESTADO:
    python version_manager.py --status Production
    # Opciones: Development, Alpha, Beta, RC, Production

RELEASE AUTOMÁTICO:
    python release.py patch              # Release completo
    python release.py minor --dry-run    # Previsualizar
