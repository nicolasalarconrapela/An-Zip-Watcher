# Guía de contribución

¡Gracias por tu interés en contribuir! Este repositorio busca ser un punto de partida claro para la comunidad.

## Cómo contribuir

1. **Abre un issue** para discutir cambios grandes o nuevas ideas.
2. **Haz un fork** del repositorio y crea una rama descriptiva:
   ```bash
   git checkout -b feat/mi-mejora
   ```
3. **Mantén los cambios enfocados** en un objetivo concreto.
4. **Actualiza el CHANGELOG** con la versión correspondiente y el detalle del cambio.
5. **Envía un Pull Request** con un resumen claro.

## Estilo y convenciones

- Escribe documentación en español cuando sea posible.
- Evita cambios no relacionados en el mismo PR.
- Mantén los archivos ordenados y con formato consistente.

## Versionado

Seguimos [Semantic Versioning](https://semver.org/lang/es/).

- **MAJOR**: cambios incompatibles.
- **MINOR**: funcionalidades compatibles.
- **PATCH**: correcciones o ajustes menores.

## Checklist antes de enviar

- [ ] Cambios probados localmente (si aplica).
- [ ] Changelog actualizado.
- [ ] Documentación actualizada.
