# Iniciación a la Shell

Repositorio de materiales para aprender fundamentos de la shell, con ejemplos progresivos y proyectos de apoyo.

## 📚 Contenido

- **Fundamentos de la shell**: conceptos básicos, comandos y flujos de trabajo.
- **Ejemplos prácticos**: ejercicios incrementales para practicar.
- **Proyecto complementario**: herramienta de monitoreo de archivos ZIP.

## 🧭 Estructura del repositorio

- `Readme.md`: guía principal y resumen del repositorio.
- `CHANGELOG.md`: historial de versiones y cambios.
- `an-detect-zip-agm/`: proyecto independiente de monitoreo de ZIPs con su propio README y changelog.

## ✅ Requisitos

- Un entorno con shell compatible (Linux/macOS o WSL en Windows).
- Para el proyecto `an-detect-zip-agm`: Python 3.10+.

## 🚀 Uso rápido

1. Revisa el contenido del repositorio desde la raíz.
2. Explora el proyecto en `an-detect-zip-agm/` si quieres ejecutar la herramienta.
3. Consulta el `CHANGELOG.md` para ver el historial de cambios.
